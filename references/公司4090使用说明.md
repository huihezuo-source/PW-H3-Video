# 公司两台 4090 的使用说明（给同事）

公司有两台装好 MiniMax H3 的机器，同一个办公室网络里的任何电脑都可以把视频任务发过去跑，不用自己装模型。

| 机器 | 局域网地址 | ComfyUI 地址 | 模型位置 |
|---|---|---|---|
| WJ | 192.168.0.186 | http://192.168.0.186:8188 | D:\ComfyUI\models |
| XW | 192.168.0.246 | http://192.168.0.246:8188 | C:\ComfyUI\models |

两台都是 RTX 4090 24GB、32GB 内存、页面文件 64GB。装的是 ComfyUI 0.44.0，模型是 H3 ref2va pruned_int8 主模型 + nvfp4 文本编码器，5 秒 640×384 20 步约 2 分钟，10 秒 448×608 约 4 到 5 分钟。

## 管理员要先做一次（机器主人做）

机器刚装好时 ComfyUI 只监听本机（127.0.0.1），别的电脑连不上。要开放给办公室网络，在每台机器上做两件事：

1. 编辑启动脚本（WJ 是 `D:\ComfyUI\start_h3.bat`，XW 是 `C:\ComfyUI\start_h3.bat`），把 `--listen 127.0.0.1` 改成 `--listen 0.0.0.0`，保存后关掉正在跑的 ComfyUI 窗口重新双击启动。
2. 放行防火墙端口：右键开始菜单 → 终端（管理员），粘贴下面一行回车：

```
netsh advfirewall firewall add rule name="ComfyUI 8188" dir=in action=allow protocol=TCP localport=8188 profile=any
```

做完后，在另一台电脑的浏览器打开 http://192.168.0.186:8188 能看到 ComfyUI 界面就说明通了。

机器重启后 ComfyUI 不会自动起，要双击一次启动脚本；想开机自启，把一个内容为 `start "" /min "D:\ComfyUI\start_h3.bat"` 的 `start_h3.bat` 放进 `Win + R` → `shell:startup` 打开的文件夹（XW 把 D: 改成 C:）。

## 同事怎么用

### 方式一：直接在浏览器里用 ComfyUI

打开 http://192.168.0.186:8188 或 http://192.168.0.246:8188，左侧「工作流 → 模板」里搜 MiniMax H3，像本机一样拖图、写提示词、点运行。生成的视频在页面右侧的队列里能预览和下载。

### 方式二：用这套脚本（Claude Code 技能）

1. 装好本仓库（见根目录 README 的「安装」）。
2. 告诉脚本用哪台机器：

```bash
export COMFY_URL=http://192.168.0.186:8188
python3 scripts/h3_ref2va.py examples/h3_job.json --wait out/video
```

3. 一条视频分成几段同时跑两台：把 `scripts/farm_machines_company.json` 复制为 `scripts/farm_machines.json`，然后

```bash
python3 scripts/farm.py jobs.json out/farm
```

谁空闲谁接下一段，一台失败会自动换另一台重试。

4. 想看进度：`python3 scripts/dashboard.py` 后打开 http://localhost:8765 ，机器列表在 `scripts/dashboard_machines.json`，把地址改成上面两台的即可。

## 一起用的规矩

- 两台机器都是一个队列，先提交先跑。提交前在浏览器里看一眼队列，别在别人跑长片段时一口气塞十几条。
- 一次提交别超过 15 秒、分辨率别超过 1280×720，内存会见底，整台机器都会卡住。长视频按镜头拆成段再用 farm.py。
- 不要改机器上 `models` 目录里的文件，也不要在上面装新节点；要加模型先在群里说一声。
- 出片保存在机器的 `ComfyUI\output` 下，会定期清理，拿到结果请及时下载到自己电脑。

## 出问题怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 浏览器打不开 8188 | ComfyUI 没起，或防火墙没放行 | 去机器上双击启动脚本；检查上面的两步 |
| 提交后一直排队不动 | 前面有人的任务在跑 | 看队列，等；或者换另一台 |
| 报内存不足或整台机器卡死 | 片段太长或分辨率太高 | 缩短到 10 秒以内、降分辨率；机器主人把页面文件保持在 64GB 以上 |
| 第一条特别慢（5 到 8 分钟） | 冷加载 45GB 模型 | 正常，第二条起约 2 分钟 |
| 出来的人物对着旁白对口型 | 旁白写进了提示词 | 旁白段的提示词里不要写台词，见 SKILL.md |

机器主人在办公室外也能通过 RustDesk 连回来维护，方法见 scripts/README.md 的「远程机器不在同一网络时」。
